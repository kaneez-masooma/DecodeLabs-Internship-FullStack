# Decode Labs - Task Manager Fullstack Project

## 📌 Overview
This is a fullstack Task Manager application developed for Decode Labs internship. It combines frontend and backend functionality.

## 🚀 Features
- Add tasks from UI
- Display tasks from backend
- Delete tasks
- Mark tasks as completed
- Real-time UI updates

## 🧱 Project Structure
/frontend
/backend

## 🛠 Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js

## 🔗 API Integration
Frontend communicates with backend using REST APIs:
- GET /tasks → fetch tasks
- POST /tasks → add task
- DELETE /tasks/:id → delete task

## ▶️ How to Run Project

### Step 1: Start Backend
npm install
node server.js

### Step 2: Open Frontend
Open index.html in browser
